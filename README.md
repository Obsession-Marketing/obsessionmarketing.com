# obsessionmarketing.com

Static site for Obsession Marketing. Plain HTML and one stylesheet, no build step.

- `index.html` home page. A commented "CLIENT RESULT" block marks where to add one real client result.
- `assets/site.css` all styles (light and dark mode).
- `book-a-marketing-call/` GoHighLevel form "Book A Call with Obsession Marketing".
- `wpautoterms/` Privacy Policy and Terms, kept at their old WordPress URLs for SMS (A2P) compliance.
- Old WordPress URLs (`faqs`, `services`, `about`, ...) redirect to the matching home page section.
- `robots.txt` allows search engines and points to the sitemap. `CNAME` holds the custom domain for GitHub Pages.

## Rebuilding
The pages are generated by `tools/build.py` (legal text in `tools/privacy.txt` and `tools/terms.txt`). Edit there, then run `python3 tools/build.py` from the repo root. The GoHighLevel chat bubble comes from `CHAT_LOCATION_ID` (the GoHighLevel account on chris@obsessionmarketing.com).
